# Germany phone drawing follow-up — 1 October 2026

The user reported that the first memory fix still crashes on an iPhone 17 Pro,
most recently at the end of computing. Worker termination alone did not establish
physical-phone feasibility. The computing-to-rendering overlap remains a likely
cause, not a measured iOS diagnosis.

Large countries on coarse-pointer devices now transfer lossless compressed drawing
chunks instead of retaining the full expanded national drawing on the main thread.
Consecutive Float32 bit patterns are differenced before gzip; every coordinate and road ID is restored exactly. The verified immutable
source graph, algorithms, tie-breaking and exported trace contracts are unchanged.

After search, the routing worker terminates before drawing preparation. One chunk
at a time is restored and uploaded. Three.js CPU attribute arrays are released
after upload; only the selected route retains expanded coordinates. Compressed
copies support subsequent searches and WebGL context restoration. Before another
search, all national road GPU buffers are disposed. The loader awaits chunk
consumption so compression never accumulates a backlog of expanded drawing chunks.

Validation includes bit-pattern wraparound and invalid-size tests, byte-for-byte
comparison of every Swiss drawing chunk through the production worker, full
Berlin–Munich bidirectional replay, A*, repeated bidirectional trace equality,
zero retained national road CPU attributes, and forced WebGL context restoration.
The full browser suite also covers normal Swiss behaviour and exports. Germany's
ambient proof covers all algorithms, territories, outlines and switching countries.

Desktop WebKit touch emulation is behavioural evidence, not a physical iPhone
memory measurement. Accounted typed-array and GPU allocations exclude the browser,
heaps, decoding temporaries, driver, framebuffers and reclamation timing. A physical
phone retest remains necessary after publishing.
